# 管理者用・六英雄戦シミュレーター

管理者ログイン後、管理メニューの「戦闘シミュレーション」（`/admin/battle-simulator`）を開く。

1. 六英雄戦の間を選ぶ。今期の上位10人を表示する。
2. 挑戦側・防衛側を指定する。名前・ID検索でも選べる。
3. 「1戦を戦闘画面で再生」を押す。実行時に本番の能力・装備・対人戦技セットを読み直し、HP/SP全快から公式戦と同じ部屋規則・計算で対戦する。
4. 再生・一時停止・前へ/次へ・速度変更・光の演出・結果表示を操作できる。
5. 戻ると部屋と対戦者の選択を保持する。「攻守交代」で逆方向も確認できる。従来どおり両方向1〜100試行の集計にも対応。

「最新状態を取得」は本番DBを読み直す。ローカルの取得済みデータや新規キャラクターを本番へ取り込む機能ではない。

模擬戦はtransactionを常にrollbackし、順位・挑戦回数・公式/練習戦績・HP/SP・報酬・ゲーム戦闘ログを保存しない。作成結果はセッション/キャッシュだけに保持し、作成した管理者本人に限定、30分で失効する。非管理者と他の管理者は閲覧できない。DBスキーマ変更なし、migrationは適用しない。

公式戦・練習戦・通常探索の計算と乱数を維持する。再生記録は模擬戦が明示した場合だけ作成し、公式戦の結果画面は既存のログ部品を使う。乱数で結果は変わるため、少数試行の勝敗だけで優劣を断定しない。
