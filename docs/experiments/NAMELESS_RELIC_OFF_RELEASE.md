# 名もなき鍛冶屋のOFF配備

2026-10-05の明示依頼によるコード・画像のみの配備。公開ワークフローはstaging/productionとも`migration_mode=none`。

## 停止条件

`NamelessWorkshopService::enabled()`はlocal/testing環境と`nameless_relics.enabled`の両方を要求する。本番・stagingではenvがtrueでもOFF。`ready()`はその後に新テーブルの存在を検査する。Controllerはすべての専用GET/POSTでreadyを要求する。専用街は登録しない。通常MAP・施設・装備画面に追加機能を表示せず、ステータス・Actorへ効果を注入しない。

通常装備のschema検査もenabledを先に要求する。ローカル試作用の既存装着資産の保護・敗北解除はlocal/testingだけで有効とし、本番から遺物テーブルを参照しない。OFF時の通常装備売却は従来経路を使う。

## 配備範囲

- 名もなき武器9種・防具6種・装飾品5種、収集・命名・保護・+99育成・吸収・付け替え。
- 遺物87種×I〜IX、通常SSS2枠/EPIC3枠、名もなき武具3枠。I〜VIは本体込み3個、VII〜VIIIは5個で次ランクへ。途中進捗・確認・UUID再送対策。
- 6遺跡、深度別ボス、ボス挑戦ボタン、入手できる遺物のアコーディオン。関連武具・遺物・敵・街画像。
- 通常装備と名もなき武具の装着遺物表示、売却不可の理由と取り外し導線。出品・特性素材・進化・敗北喪失の連携。

共有ファイルは最新本番を基準に追加分だけ移植し、国家限定/宛先指定市場、SP出力・百分率威力・防御式、時間切れ敗北表示、設定snapshotを維持する。

## DBと開放時の残作業

5本の関連migrationはコードとして含めるが実行しない。既存DB・工房街・プレイヤー資産の作成/更新なし。ON公開時はゲートの変更を別途裁定し、本番互換migration（SQLite限定定義を含む）、街登録、正式バランス、MariaDBの並行操作/再送、認証済み実プレイとスマホを改めて検証する。flagだけの変更では本番は開放されない。

## 検証と復旧

機能テストは独立したメモリDBで実行。本番/staging境界と未migration状態は`NamelessProductionOffTest`で確認。既存市場の購入制限・装備性能・戦闘・探索の回帰テストとビルドを行う。公開後に公開SHA、health、環境ゲート、DB未変更、認証境界、ログ差分と直前リリースを読み戻す。問題時は標準公開手順で直前のリリースへ戻す（DB変更なし）。
