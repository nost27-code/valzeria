# 遺跡の深度別ボスと対策

2026-10-05。ローカル実装。各遺跡4体、合計24体。深度1〜24／25〜49／50〜74／75〜100で切り替わります。

基礎能力と深度倍率は従来の式を使用。特徴行動は既存PvEのボス抽選30%に従います。強打は物理150%、鎧砕きは防御20%低下・3ターン、二連撃は物理80%×2、呪光は魔法150%。最奥の物理大技は200%、魔法大技は150%で、1手番の予兆・cooldown 4・初手使用不可。既存の自動戦闘・戦技の予兆対策へ接続します。

予兆中の撃破で大技は不発。初護の楔は最初の攻撃行動全体を軽減しますが、後の大技や繰り返す連撃への備えには耐性やHPが必要です。通常の防御・精神・戦技でも対処でき、推奨遺物は必須条件ではありません。本資料の対策と推奨遺物は開発用の記録です。人間裁定により、ゲームの探索画面にはボスのヒントを表示しません。

## 実装範囲

- 深度別ボスの正本は config/nameless_ruin_bosses.php。通常敵4体・既存の最奥ボス参照は config/nameless_ruins.php に保持。
- NamelessRuinService が挑戦と撃破済み再遭遇の両方を選出。新しい保存結果に特徴と対策を記録し、旧結果は従来どおり表示。
- 探索タブのボス画像・特徴・対策・推奨遺物のカードを削除。大陸と同じ赤い「ボスに挑む」ボタンだけを表示。深度選択は挑戦時のボス選出に使用。
- 新しい18画像は public/images/enemy/ruins/ruins_boss_*.webp。各300×300、透過。既存6画像は保持。
- DBスキーマ変更・seed・既存プレイヤー所有行の更新は不要。探索力1/3、ドロップ20%/60%、深度50の次遺跡解放、深度100の撃破記録は既存規則を使用。
- 実プレイヤーでの戦闘、MariaDB、実機Safari、本番反映は未実施。
