# 遺物87種類の実装一覧（2026-10-04、ローカル）

現行configと `NamelessRelicCatalog` から生成した一覧。既存29キーは保持し、新規58種類を追加した。数値は人間から判断を委任されたローカル試作値で、本番未反映。

## 能力と装着の共通ルール

遺物を除いた装備込み能力を一つの基準にして割合を加算する。同じ能力の増加分は武器・防具を通じて30%まで、代償の減少分はその後に差し引く。乗算を重ねない。攻撃20,000に単能力IXなら23,000、複合IXなら対象二能力が各10%増える。

武器・防具は各3枠。同効果は一本の武具内と装備中の組み合わせで一つまで。敵への刻印・自分の変身・通常攻撃の変換は、それぞれ一種類まで。控えの別武具へ競合する組み合わせを試すことはでき、持ち替え時に再検証する。

## 戦闘での扱い

- 通常PvE・ボス・遺跡と、共通PvPエンジンの闘技場・六英雄戦で有効。勝利後HP/SP回復はPvEだけ。raidと独自の塔Actorへの特殊効果は追加していない。共通能力の割合補正は共通ステータス利用先に反映される。
- 特攻・耐性はPvPで効力75%。特攻は合計30%、耐性は35%まで。自然種族や変身の種族と敵からの刻印は加算しない。PvPは複数種族への一致でも最大の一系統だけを採用。PvEの複数自然種族への特攻は従来の一致分合計を維持し、刻印由来と比較して大きい方を使う。同じ種族の装備・遺物の率は合算してから上限処理する。
- 敵への刻印はIから戦闘開始時に確定付与。ランクで刻印由来の特攻の効力が40〜80%になる。刻印は装備・遺物の種族判定だけに使い、職業技の種族判定には追加しない。自分の変身は実戦Actorの種族を変えるが、キャラクターの保存情報は書き換えない。
- IXの竜刻＋竜特攻をPvPで使用すると、28%×80%×75%=16.8%増。断刻IXで追加分を60%抑えると6.72%増。浄刻は最初の自分の手番で刻印を必ず除くため、先制された攻撃には間に合わず、変身には効かない。
- 防御/精神貫通は既存の戦技・敏捷突破と合わせて50%まで。既存だけで50%超なら遺物は追加せず、元の貫通を弱くすることもしない。
- 追撃・反撃・鏡返しは同じ攻撃行動に一度、反応から別の反応は起こさない。手番・SP消費・戦技クールダウン・灼命の行動末自傷を増やさない。追撃/反撃は実際のHP減少を基準にし、盾や過剰ダメージを吸収・追撃へ変換しない。
- 血杯の回復は既存の場・部屋の回復補正を通る。背水の契約は戦闘中のHP回復を止める。反撃で倒れた攻撃者の残りHitと後続回復は止め、戦闘中に復活しない。
- 踏みとどまりは既存の根性と一回分を共有。自傷・反動・継続ダメージには遺物の踏みとどまりを適用しない。狙眼は現行の各経路の会心上限内（PvE30%、PvPランク式12%）。
- 遺物はI〜III=3pt、IV〜VI=4pt、VII〜IX=5ptとして強化に投入できる。保護・装着中は不可。食わせても効果は本体へ永続継承しない。
- 戦技設定や構成診断の固定SP表示、職業技のダメージ試算は遺物を含まない従来の試算。実戦の節魔・貫通は上記フックで適用する。
