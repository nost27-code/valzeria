# 遺物拡張の実戦式による数値確認（2026-10-04、ローカル）

人間から未裁定値の判断を委任され、闘技場・六英雄の実際の実装と模擬戦を参考に試作値を決定した。本番へ公開していない。結果をゲーム全体の勝率や正式バランスの保証として扱わない。

## 比較の方法

ローカルDBのレベル上位30人を読んで、装備込み攻撃/魔力が最大の一人を基準に採用。同じ既存職業と実際にセットされた戦技を使う二人のメモリ上のコピーを作り、共通 `PvPBattleService::resolveBattle` を実行。闘技場は訓練場コンテキスト、六英雄は各部屋の練習コンテキストを使う。正式戦と共通のダメージ式・戦技・部屋規則を通るが、公式対戦ログや挑戦料を保存しない。全処理はローカルのtransactionでrollbackする。

基準の職業は暁の勇者。全職業や本番上位層の分布ではない。観測したローカル基準に加え、人間が伝えた上位層の1.5万〜2万を参考に、全8能力と装備前SP基準を同比率で拡大した二つの仮想プロフィールを使う。実在する1.5万/2万のプレイヤーを採取したものではない。

各条件20戦。先攻側Aの勝利数を記録し、勝率の精密な推定・統計的有意差の検定は行っていない。同一条件でも乱数・先後関係・部屋の制限が影響する。封刃で物理主体の同職業が時間切れになるなど、今回の職業に固有の状況も含む。戦技マスタ・職業・部屋ルールは変更していない。

## 採用した強さと理由

- 単能力IX15%、複合各10%、全能力各5%。上位能力20,000で単能力なら+3,000となり、既存の固定+56を置き換える。各能力の正の合計30%上限で多枠の積み重ねを制限し、代償の減少は別に残す。
- 単種族特攻IX28%、耐性IX20%。PvPでは75%へ縮小し、特攻上限30%・耐性上限35%。相手を刻印するにはもう一枠が必要で、IX刻印80%との積は16.8%増。対抗枠の断刻IXは追加分だけ60%軽減し6.72%増、浄刻は最初の自分の手番で確定解除する。
- 変身はIXで二能力各15%増と種族変更。種族特攻を受ける弱点が増え、刻印解除では自分の変身を消せない。複数の変身/刻印/攻撃変換はそれぞれ同時に一種まで。
- 追撃はIX25%で実HP減少の30%を追加するため、通常攻撃への期待追加は7.5%。反撃はIX25%で実HP減少の25%を返し、期待値6.25%。鏡守はIX12%軽減と軽減分の25%返し。どれも追加手番・反応の連鎖を発生させず、各攻撃行動に一回まで。
- 血杯IXは通常攻撃の実HP減少の12%回復。既存の回復補正・灼命の回復制限を通す。反響IXは通常攻撃命中で最大SP1.2%回復。背水の契約IX25%は全直接攻撃を強める代わりに戦闘中HP回復を止める。
- 貫通IX20%は既存技/敏捷突破と合成後50%まで。戦技による貫通が既に上限へ達している場合は遺物を追加しない。不屈IXは最大HP8%を残す一回分、既存の根性と共用し、灼命の自傷には効かない。

## 確認できたことと限界

効果の大きさと対抗方法を現行のダメージ式・行動規則へ接続した。全87種の定義・ランク順・入手可能性、割合上限、持ち替え・装着の排他、部屋規則、盾/実HP減少、反応の連鎖禁止、反撃後の死亡、公式ログ/所有データを保存しないことは隔離テストでも確認する。

未確認は、本番資産分布、全職業/戦技/最大6枠の全組み合わせ、MariaDB並行処理、実機iPhone Safari、長期運用での収集速度と経済。遺物の狙い撃ちIXは候補増加でさらに希少になる。現行のドロップ率・ランク希少性・費用と救済なしの方針は維持しており、今回の模擬戦は育成時間の妥当性まで保証しない。
