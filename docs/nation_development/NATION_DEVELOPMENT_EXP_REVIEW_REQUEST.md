# 国家納品・国家レベル仕様 レビュー完了記録

- 初版作成日: 2026-08-25
- 最終更新日: 2026-08-25
- 対象: 都市素材の国家納品、国家発展EXP、国家レベル
- 文書状態: レビュー完了 / 実装済み / 本番公開前
- 対象DBMS: MariaDB 10.5.13以上

## 1. レビュー結果

ゲームデザインと実装安全性のレビューを2回実施し、総合判定は「実装へ進行可」です。既存在庫、20人国家、資材用途競合、Lv50後の扱い、冪等性、transaction、row lock、MariaDB index、退会者の貢献表示まで確認しました。

## 2. 最終仕様

### 対象素材と換算

既存の都市素材40種を使い、新しい国家専用素材は追加しません。

| 区分 | 対象数 | 国家資材 | 国家発展EXP |
|---|---:|---:|---:|
| 既存1pt対象 | 20種 | 1個=1pt | 1個=1EXP |
| 既存3pt対象 | 20種 | 1個=3pt | 1個=2EXP |

国家資材は施設・国家戦向けの消費残高、国家発展EXPは減らない累計実績です。換算率は同じmaster rowの別カラムへ保持し、将来どちらかだけを調整できます。

### 国家レベル

- 初期Lv: 1
- 表示上限: 50
- 現在Lvを`L`とした次Lv必要EXP: `500 × L`
- Lv`N`の累計閾値: `250 × N × (N - 1)`
- Lv50累計閾値: 612,500EXP
- Lv50後も生の国家発展EXPを破棄せず保持する
- float逆算を使わず、最大49回の整数閾値比較でLvを判定する

Phase 1の国家Lvは表示・名誉値です。能力補正、施設Lv解放、国家戦補正は設けません。

### 増減ルール

国家発展EXPが増えるのは、現在国民が対象都市素材を自国へ正常に納品した場合だけです。国家資材の消費・返却・補填、施設強化・修理・再建、戦争、敗戦、施設損傷、脱退・追放・役職変更では増減しません。日次・週次の納品上限とEXP上限は設けません。

### 表示

- 国家外の冒険者: 国家Lvだけ
- 現在国民: 累計EXP、次Lvまでの進捗、現在国家での個人貢献、国民別貢献
- アカウント削除済み: `退会した冒険者`として1行へ集約
- 納品画面: 納品数、納品後残数、獲得国家資材、獲得EXP

対象素材は装備進化・素材交換・NPC調達にも使うため、納品前に警告します。進化経路ごとに必要数が異なるので、「進化に必要な残量」は自動計算しません。

## 3. DB・整合性

### 正本とcache

- 正本: `SUM(nation_resource_transactions.development_exp_delta)`
- 読取cache: `nations.development_exp`
- 過去の換算率変更に影響されないよう、納品時のEXP差分をimmutable台帳へ保存する
- 個人貢献用の別集計tableは作らない

`nation:audit-development`は既定read-onlyで照合します。明示的に`--repair`を付けた場合だけ、台帳合計を正としてcacheを復元します。

### lock順序

国家資材を変更するtransactionでは次の順に固定します。

1. `nations` 排他lock
2. `nation_memberships` 排他lock
3. `nation_material_conversion_rates` 共有lock
4. `character_materials` 排他lock

換算率は共有lockとし、同じ素材の納品を全国家横断で排他直列化しません。施設強化も国家rowを先にlockします。

### 冪等性

同じ冪等キーの再送は、Character・素材・数量が前回と一致する場合だけ前回結果を返します。異なるpayloadでのキー再利用は拒否します。

### index

MariaDBには`INCLUDE`がないため、貢献集計用に次のcovering indexを持ちます。

```text
(nation_id, transaction_type, character_id, development_exp_delta)
```

## 4. レビュー時の数値確認

最終の1/2EXP換算スナップショットでは、所有者703人、全員合計421,863EXP、1人最大10,484EXP、上位20人合計94,028EXPでした。上位20人の理論全量納品はLv19で、Lv20まで972EXPです。

旧資料の素材別数量から算出した423,297EXPは別時点のスナップショットです。異なる取得時点の数値を同一集計として混在させません。

施設Lv1→10の全施設合計費用151,810ptは国家資材換算と発展EXP換算が異なるため、国家Lvへ一意には対応しません。

- 高位素材中心: 約101,207EXPでLv20
- 低位素材中心: 151,810EXPでLv25

## 5. 公開後のPhase 2計測

公開から2〜4週間後に台帳から次を確認します。

- 1EXP素材と2EXP素材の納品数量・利用者比率
- 国家ごとのLv分布、Lv10/Lv20到達日数
- 20人国家と少人数国家の成長差
- 上位国家への集中度
- 納品後に素材不足の問い合わせが増えていないか

1pt/3pt素材の納品比率が極端な場合は、まず国家資材pt側の役割を再評価します。Phase 1では1pt素材=余剰処分、3pt素材=資材本命という役割分化を許容します。

## 6. 公開境界

- `NATION_DEVELOPMENT_ENABLED`を国家コミュニティ・国家戦から分離する
- ローカル/テストは既定ON
- 本番は明示ONまでOFF
- `NATION_WAR_ENABLED`、宣戦、施設Lvアップ、基準Dは変更しない
- `WEV0030`の敵dropは後続裁定により国家戦flagから独立して有効化する
- 発展実績の記録後は通常の`migrate:rollback`を実行しない。同一release batchの入口でも実績を検知して部分rollbackを拒否し、障害時は発展flag OFFとforward migrationで復旧する
